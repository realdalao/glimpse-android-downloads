# Glimpse Android downloads

Public binary downloads for the Glimpse Android client. This repository contains release assets and download notes only; the Android source repository remains private.

## Latest preview

**Glimpse Android 1.0.1 Debug Preview 1** is a debug-signed APK for sideload testing, not a Play Store release.

- [Download APK and checksums](https://github.com/realdalao/glimpse-android-downloads/releases/latest)
- Application ID: `com.glimpse.mobile`
- Android 8.0 (API 26) or newer

The app pairs with a Glimpse Relay. Profile and interview-role editing require authenticated `/api/profile` and `/api/jd` routes in the desktop Relay.
